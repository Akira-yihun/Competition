## 需求与实现

| 用户需求 | 本次方案 |
|---|---|
| 迁移后路径有效 | 区分工作区 `2026 HW Comp/`、Git 根 `CoreGeek/`、工程根 `CoreGeek/ChatGPT/`；官方材料位于工作区 `docs/`。修复参考脚本、文档链接、配置 project_root；git_root 仍指向 CoreGeek。历史源码摘要从原始 Git 提交读取，不把迁移后的新源码冒充历史快照。 |
| 每回合日志分行、保留 req/rsp | 默认第一行 `ROUND n`，第二行 `req {JSON}`，第三行 `rsp {JSON}`；随后依次输出官方新闻、民间传闻、任务要求、LLM 返回、prompt、命令返回、executeCmd。输入输出保留全部字段和值，不截断；空白规范化、字符串换行转义，确保原始对象各占一行。入队前复制原始对象，避免异步写入期间被修改。 |
| 近敌优先、火箭覆盖后排 | 对本阵营敌人按到基地占地的距离排序。每发火箭的候选中心仅在最近可打击敌人的九宫格中选取；密集队列或后排强敌存在时，倾向沿地图内侧方向后移一格，同时让前排处于溅射范围。最近敌人已进入基地三格范围时优先直击。多发火箭扣除预计伤害后继续选目标。 |
| 前线武器优先升级 | 根据基地左右位置镜像确定进攻方向；优先地图内侧的炮塔，其次参考攻击本阵营的机器人距离，再按等级与 ID 排序。白天采购使用、夜间就地使用采用同一规则。现有三炮背侧集中布局保留。 |
| 固定矿点、价格距离权衡 | 选矿考虑新闻价格估计、实际可走路线和到小贩距离，等价价格下优先近矿。保存矿点坐标和种类，价格变化不会每回合切换目标。观察到矿点消失或类型改变则释放目标；满包销售后可以返回原矿点。石材也按矿点采完或满包后再用于建设。 |
| 夜间远离中路 | 日内第 61 回合起启动避险。普通采矿、任务和宝藏目标限于左右外侧约三分之一区域；路线禁止从侧面横穿中间区域，并避开存活机器人周围四格。已处于危险区域时先撤离；无安全路线时尝试减少威胁的合法一步。防守工人返回操作位与紧急回血可豁免普通经济路线限制。 |
| 尽快购买升级券、基地低血回血 | 完成三炮后，先完成一次武器升级，再由防守工人购买并保留一张匹配当前基地等级的升级券，随后继续按前线顺序升级武器。此采购优先于补完围墙。基地健康时不消耗券；低于 100 血，或五格内面向本阵营的敌人按官方类型攻击力估计两回合伤害足以致命时，优先赶到基地并使用。 |
| 每次优化可回溯 | 工程 README 约定后续每轮新增 `docs/design/` 归档，记录需求、实现、验证及局限，保留历史结论。本文件为本次记录。 |

采矿目标锁定允许必要的满包出售、建设、防守召回和危险撤离中断。接口不提供矿山剩余储量，不能凭空宣称已知道剩余次数；以观察到的地图变化判断耗尽，官方十次耗尽规则用于测试场景。夜间小贩或商店位于中路时延迟交易至白天，避免为了出售进入危险区域。

日志末尾保留一行 `diagnostics {JSON}`，记录解析、动作校验、角色分工等诊断信息；该行长字段仍可能截断，完整正文见 req/rsp。`tools/analyze_debug.py` 同时读取新格式和旧 NDJSON。`CORE_GEEK_LOG_FORMAT=ndjson` 可切回单行事件，`CORE_GEEK_DEBUG_LOG=off` 可关闭；异步队列满时仍可能丢弃整条事件，并在后续事件计数。

## 验证

- 全部 94 项测试通过，包含 HTTP 服务、解压包入口、日志字段、镜像前线排序、近敌与后排覆盖、矿点锁定与耗尽、夜间移动、基地保券及预测回血；新增 10 项针对本轮需求的回归测试。
- 旧首日建设测试曾设置 100 次矿山储量，与官方 10 次规则不符。改为 10 次，并验证首日三炮、矿点耗尽和围墙建设；本轮策略不再承诺采购升级优先时首日必定建满 16 格围墙。
- 文档所需文件、JSON、所有文档内本地 Markdown 链接及 10 项原始资料摘要校验通过；官方示例请求探针与加特林锥角探针通过；`git diff --check` 通过。
- 完整本地近似模拟：种子 1，左右各 1300 回合。两边基地均存活，最终血量均为 1500；防守工人分别在第 148、150 回合购买并保留基地券，健康时未消耗。最高直接决策耗时约 67.4 ms（不含 HTTP/进程启动）。模拟结束后仅补充日志对象复制与测试/说明整理，战斗和经济策略未改动。

## 交付与后续边界

[提交包](../../artifacts/coregeek-v0.5.tar.gz)，SHA-256：`9b88793458baa1519822873ffed10680a9ccb97d91785a28c9fcfb47730ea29e`。包内包含 main3.py、pyproject.toml、agent 源码和 MANIFEST；不含本地 run.sh、日志、测试、实验室和文档。入口保持 `python3 main3.py PORT`，平台脚本约定保持原状。

# 文档读取、更新与归档

先读 [工程交接](../AGENT.md)。本目录是工程文档；官方规则在工程根的../../docs，只读。文档矛盾时先分辨官方事实、当前源码、历史方案和推测，不把设计承诺当实现。

当前实现主入口是design/08-v07角色目标与沙盒任务实施.md与工程README。design/07-v06候选优化方案评审.md是多Agent候选方案；01—06及本目录早期交接材料保留历史背景，有尚未实现的设计（例如部分平台闭环、公钥日志、成功SOP验证）。阅读时不能据旧文档声称功能已落地。

每轮优化新建编号文件，不覆盖历史结论。建议结构：日期／代码基线；用户原始需求；官方依据／回放证据；候选方案与取舍；模块与实施顺序；验收场景；实际修改；测试命令与结果；对比表；未验证部分；日志和包位置。先写方案，再实施补结果。仅评审任务不修改运行时代码。

README记录当前使用方式，交接AGENT.md记录接手路径与长期不变量；新版本变更后同步入口和版本号，历史归档仍保留原数值。路径相对于所属Markdown文件解析；含空格的shell路径加引号。不要复制私人凭据、平台令牌或大段日志到交接文件。

检查：在工程根运行 `python3 -B docs/reference/check_docs.py`。它覆盖本docs目录的链接、JSON与来源快照，但不等于策略测试，也不覆盖所有根／源码AGENT.md的链接；新增交接链接需单独检查。来源快照若变更，先解释官方材料版本变动，不能随便重写哈希使校验变绿。

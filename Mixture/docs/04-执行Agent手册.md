# 执行 Agent 手册：本地工具 + 已安装的平台 Skill

当前闭环规划见 [02-Loop工程计划](02-Loop工程计划.md)。平台登录、上传答案、对战和拉日志由用户在执行Agent上固化的skill完成；不开发网站API适配器，不要求补旧端点配置。当前仓库loop.cli仍是本地子流程，正式阶段由外层Agent调用skill编排。


## 接手核对

- 源码与包：main3.py不改，run.sh仅本地；tools/package.py打包工作树，需核验实际哈希。
- 验证：按 [测试交接](../tests/AGENT.md) 运行；v0.7的109项通过是历史记录，修改后重新检查。
- 正式流程：skill身份、登录会话、队伍、提交版本、对手、预算和日志输出目录有证据；缺失只补必要信息。
- 恢复：未知上传／开赛结果先对账；已进行的比赛继续查状态，不能因等待超时重复发起。
- 日志：当前为明文回合日志，公钥加密未实现；不要求用不存在的解密功能。比赛内executeCmd不得在开发主机执行。

## 每轮报告

使用 [模板](templates/iteration-report.md)：假设、基线／候选、差异、本地检查、包哈希、skill执行记录、平台版本、比赛及半场、官方结果、日志覆盖、预算、保留／拒绝／证据不足、下一轮单一假设。失败回合必须能追溯到具体比赛和输入输出，不能只给泛化建议。

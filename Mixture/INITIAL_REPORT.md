## 子 agent 挑战及修订

独立策略挑战 agent、模拟器 agent、HTTP 测试 agent 分工审查；最终整合、HTTP阻塞诊断与产物验收由主 agent 完成。

| 挑战问题 | 处理 |
|---|---|
| 加特林轴向候选形成钝角，且目标数必须等于等级 | 逐对点积非负；补不同合法落点，避免依赖未确认的重复落点 |
| 样例射程与任务书矛盾 | 文档与有效观测取较小值，INT_MAX不让一级火箭变全图 |
| 三塔限制与两工共享预算 | 按所有存活塔计数，建设和升级预留预算与目标 |
| 换边塔位不对称 | 三塔布局180度变换，保留通道 |
| 不可达塔位导致工人永久召回 | 不可达路径不触发白天召回 |
| 任务旧响应串入、夜间离开任务点 | 任务摘要+上一回合编号验证，任务中锁住开拓者；命令结果用于后续解题 |
| 公共商店重复碰撞 | 上轮失败时重选等长路径；同批候选碰撞从100次降至7次 |
| 模拟器错误处理/规则校验不足 | 补齐顶层协议、坐标、夜建、升级相邻与错误分层测试 |
| HTTP监听前阻塞 | 实测定位标准库反向DNS阻塞；绑定时不做反向DNS |

## 来源与局限

最终模拟运行时的脑、协议、寻路、原版快照和模拟器哈希与交付一致；之后只修改了HTTP服务的DNS启动逻辑，已通过真实HTTP及解压包测试。summary保留当时的server哈希，不改写历史证据。

## 3. `server.py` 的具体改动（最高风险面）

| 项 | 基线 | 现在 |
|---|---|---|
| 响应体 | `{"roleCommandMap": {...}}` | 三键齐全且类型正确，任何路径都经 `envelope()` |
| 解析异常 | 兜底 `{"roleCommandMap":{}}`（仍缺两键） | 兜底完整空信封 |
| `Content-Length` | 在 `try` 外，`int("abc")`/缺头会让异常逃出 `do_POST` ⇒ **不返回响应 ⇒ 必然超时异常** | 全保护，异常/超长/负数一律当 0 或拒绝，仍返回合法信封 |
| HTTP 方法 | 只有 `do_POST`，GET 返回 501 | `GET`/`PUT` 都返回合法信封 |
| 请求体上限 | 无 | `config.max_body_bytes`（默认 8 MB） |
| 日志 | 每回合把**完整响应**写 stdout（泄题 + 管道写满阻塞进程） | 只写摘要（回合号、动作名、是否带 prompt），且仅在 INFO 级 |
| 反向 DNS | 未禁用 | `BaseHTTPRequestHandler.address_string` 不参与响应路径；`server_version`/`sys_version` 固定 |

## 4. 关键不变量（改动时不要破坏）

1. **响应只有一条出口**：任何新增返回路径都必须经过 `protocol.envelope()`。
2. **解析永不抛异常**：任何新字段都用 `model.as_int/as_str/as_list/...` 读，禁止硬索引。
3. **`guard` 只做减法**：不允许在 guard 里"补一个更划算的动作"。
4. **`attack` 的 key 是武器 id，不是操控者 id**：`controllerId` 指操控角色，`roleCommandMap` 的键指被指挥的单位（官方样例：key `10020`=加特林，`controllerId` `10010`=工人）。这一条曾经写错并导致整局非法指令，`tests/test_contract.py` 有回归。
5. **攻击目标数严格等于等级、两两互不相同、加特林过锥**：凑不满就不发攻击。
6. **昼夜边界留 ±1 缓冲**：`build` 只在 `phase ≤ 68`，`attack` 只在 `phase ≥ 72`。
7. **任务态开拓者不得离开任务点一格**：夜间调度必须把它排除在操炮名单外。
8. **匹配作用域记忆必须随局次清空**：`SiteKnowledge`、任务实例、价格日历在换局/换边/回合回退时重置；技能库保留。
9. **金币用 `plan.available_gold(obs)`**，不要直接读 `obs.gold` 做多次支出。
10. **`main3.py` 不动**：它只导入 `agent.server.serve`，所有改动都必须在这条边界之内。

## 6. 继续开发时的建议顺序

1. **接线 `executeCmd`**（唯一还没接的协议面）：任务态下发单条、幂等、无外网的 `python3 -c` 命令，把 `[TIMEOUT]`/`[JUDGER_ERROR]` 一律当"无证据"。
2. **情报闭环**：让 `PriceCalendar` 影响采集/售卖时序，让 `should_summon` 在信心门限满足时真正发 `summonTreasure`。
3. **技能库升级为 solver 编译**：把一次成功的解题过程固化成确定性代码，使同型任务零模型调用、单回合完成。
4. **建址探测独立配额**：若主办方确认"区外建造"属"指令非法"，加硬计数上限（每局 2 次）。
5. **围墙维护循环**：`remove` + `WallFixer` 接入策略层。
6. **向主办方确认清单**：`build` 的 `name` 词表、可建造区坐标定义、`roundNo` 是否 0 基、`errors[]` 与异常次数的映射。
